# Knot

Local-first meeting summarizer. Record or import a meeting, transcribe it on your laptop with Whisper, let a CrewAI crew (Gemini) produce summary, decisions and action items, save the notes to Notion over MCP, and ask follow-up questions through a local RAG index.
